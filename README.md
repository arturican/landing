# landing

Учебный проект — адаптивный лендинг на HTML/CSS.

## Структура

- `index.html` — основная страница.
- `styles/main.css` — стили страницы.
- `images/` — изображения контента.
- `.prettierrc` и `.prettierignore` — конфигурация форматирования.

## Команды

- `npm run format` — форматирует все `*.html` и `*.css`.
- `npm run format:check` — проверяет форматирование всех `*.html` и `*.css`.
